FAQ

Perguntas frequentes.

Preciso saber montar computador para usar?

Não. O simulador foi pensado para iniciantes: cada etapa é guiada e explica a função da peça que você está encaixando.

O que acontece se eu encaixar algo errado?

Nada quebra. O simulador indica o problema e mostra como corrigir, para que o erro vire aprendizado.

Quanto tempo leva uma montagem completa?

Poucos minutos. A experiência foi desenhada para sessões rápidas durante a visita ao estande.

Onde posso experimentar?

No estande do projeto durante a FENECAN. Procure a equipe para começar a sua montagem.
